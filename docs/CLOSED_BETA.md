# Moduscript 封闭测试协议

## 适用范围

| 场景 | 说明 |
|------|------|
| **自托管开源版** | 使用本仓库自行部署的实例；不受下方「封闭测试」条款约束，但须遵守 [LICENSE](../LICENSE)（AGPL-3.0）与 [LEGAL_NOTES.md](LEGAL_NOTES.md) |
| **官方封闭测试站** | 由项目维护者运营的公开注册测试环境；适用本文档全部条款 |

## 测试性质（官方封闭测试站）

Moduscript（模词成稿）目前处于**封闭测试**阶段。本站面向公众开放注册，但功能、界面与数据存储方式均可能随时调整，不构成最终产品承诺。

## 用户须知

1. **数据存储**：用户数据（账号、会话、偏好设置）以服务端 **JSON 明文文件** 形式存储于 `data/` 目录。请勿上传密码、密钥等敏感信息至任务描述或参考模组说明中。
2. **API 调用**：编写任务将通过服务端配置的 LLM API 转发至 Claude Agent SDK。测试阶段可能使用平台统一 API Key。
3. **数据丢失风险**：封闭测试期间不保证数据永久保留，服务重启、迁移或测试结束可能导致数据清除。
4. **反馈**：欢迎通过管理后台配置的反馈邮箱或项目 Issue 提交问题与建议。

## 注册即表示同意（官方封闭测试站）

注册账号即表示您已阅读并同意：

- 自愿参与封闭测试，了解功能尚不完善；
- 自行承担测试期间的数据丢失与服务中断风险；
- 遵守相关法律法规，不得利用本平台生成或传播违法内容。

## 隐私概要

- 收集信息：注册邮箱、密码哈希、会话内容与偏好设置。
- 用途：提供模组编写 Agent 服务、封闭测试运营与问题排查。
- 共享：除 LLM API 提供商（按任务需要发送 prompt）外，不向第三方出售用户数据。

## 退出测试

您可随时停止使用并联系管理员删除账号数据（删除账号功能将在后续版本提供；当前可联系管理员手动处理）。
